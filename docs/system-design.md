# System Design — Receitando

A arquitetura atual do Receitando combina **frontend Next.js/React responsivo**, **API REST stateless em Cloudflare Workers**, **Neon PostgreSQL 17 via Hyperdrive**, **R2 para imagens** e **Durable Objects/WebSocket para o Receitando Juntos**.

O documento completo da **Fase 4** contém definições, diagramas, estratégia de **1 milhão de escritas para 2 milhões de leituras**, mapeamento de pagamentos, integração WebSocket, evidência SQL e limites de capacidade.
